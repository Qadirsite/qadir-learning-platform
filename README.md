# قادر — منصة تعليمية ولوحة إدارة

قادر منصة تعليمية عربية مجانية للقدرات والتحصيلي، مع واجهة زوار ومساعد تعليمي ولوحة إدارة مستقلة على `/admin`.

## المتطلبات

- Node.js 22 أو أحدث، وpnpm 11.
- قاعدة MySQL متوافقة مع المشروع.
- لتشغيل النسخة المحلية على بياناتك، اضبط `DATABASE_URL` و`INITIAL_ADMIN_PASSWORD` في بيئتك الآمنة. لا تضع القيم في ملفات المستودع أو ترسلها عبر المحادثة. كلمة المرور الأولية تنشئ حساب `ak9` مرة واحدة فقط.
- استدعاء مساعد Manus وتخزين الملفات يعتمدان على إعدادات خدمات Manus الموجودة في بيئة النشر. لا تُضمّن مفاتيح الخدمة في الواجهة.

## تشغيل محلي

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm start
```

يستمع التطبيق على `PORT` أو المنفذ 3000 افتراضيًا. عند بدء الخادم تُطبّق migrations المسجلة على قاعدة البيانات التي اخترتها. لا تستخدم قاعدة إنتاج مشتركة للتطوير أو اختبارات تُنشئ/تحذف بيانات.

## متغيرات البيئة الاختيارية

| المتغير | الافتراضي | الوظيفة |
| --- | --- | --- |
| `TRUST_PROXY` | `auto` | قراءة عنوان الزائر الحقيقي من `X-Forwarded-For`. `auto` يثق بالترويسة فقط إذا جاء الطلب من وكيل داخلي (عنوان خاص أو loopback)، و`false` يتجاهلها، ورقم مثل `1` يعني الوثوق بعدد من الوكلاء. يُستخدم لحدود الشات ومحاولات الدخول. |
| `CHAT_GLOBAL_PER_MINUTE` / `CHAT_GLOBAL_PER_DAY` | `500` / `10000` | سقف رسائل المساعد لكل المنصة. |
| `CHAT_IP_PER_MINUTE` / `CHAT_IP_PER_DAY` | `60` / `1200` | سقف كل زائر حسب عنوانه (IPv6 حسب /64). |
| `CHAT_DEVICE_PER_MINUTE` / `CHAT_DEVICE_PER_DAY` | `8` / `80` | سقف كل متصفح. |
| `CHAT_MAX_CONCURRENT` | `250` | أقصى طلبات مساعد متزامنة قبل الرد بـ 503 مؤقت. |
| `COOKIE_SAMESITE` | `None` | `Lax` أو `Strict` أو `None` (`None` يتطلب `COOKIE_SECURE`؛ وهو الافتراضي لمعاينة HTTPS المضمّنة). |
| `FRAME_ANCESTORS` | `'self'` | من يحق له تضمين الموقع في iframe (يدخل في ترويسة CSP). |

**للإنتاج:** اضبط `COOKIE_SAMESITE=Lax` (أو `Strict`) إذا لم تحتج تضمين الموقع في iframe؛ الافتراضي `None` مخصص لمعاينة HTTPS المضمّنة فقط. رمز CSRF مرتبط الآن بكوكي الجلسة، فيجب أن يطلب العميل `/api/auth/session` مع الكوكي نفسه.

**حماية الدخول:** بعد 10 محاولات يُحظر المفتاح (اسم المستخدم + عنوان الزائر) 15 دقيقة، وتتضاعف المدة مع كل حظر متكرر خلال 24 ساعة حتى 4 ساعات. العدّادات في ذاكرة العملية.

**تغيير كلمة المرور:** `POST /api/auth/password` بجسم `{ current, next }`، يتطلب جلسة وCSRF وكلمة المرور الحالية، ويبطل بقية جلسات الحساب ويُبقي الجلسة الحالية. لا توجد له واجهة بعد.

حدود المساعد محفوظة في ذاكرة العملية؛ عند تشغيل أكثر من حاوية يُطبَّق السقف على كل حاوية على حدة.

## حذف الحساب

يستطيع الطالب حذف حسابه من قائمة الحساب بعد إدخال كلمة المرور وتأكيد الحذف (`POST /api/auth/account/delete`، يتطلب جلسة وCSRF). ويستطيع المدير المخول بصلاحية `users.manage` حذف حسابات أدنى رتبة من لوحة الإدارة (`POST /api/admin/users/delete`) بعد تأكيد صريح وCSRF. يُحذف الحساب وجلساته ورسائل التواصل المرتبطة به، وتبقى سجلات الإدارة بلا ارتباط بالحساب. الحساب الإداري الأساسي `ak9` والحساب الحالي وأي حساب مساوٍ أو أعلى رتبة محمية من الحذف.

## الصفحات الأساسية

- `/` الصفحة التعليمية الحالية.
- `/chat.html` مساعد القدرات والتحصيلي، مع مرفق صورة مؤقت يُرسل إلى الخدمة ولا يُحفظ في قاعدة البيانات.
- `/admin` مدخل النظام الإداري؛ تتطلب صفحة اللوحة وصلاحيات API حسابًا إداريًا وجلسة صالحة.
- `/library.html` مكتبة المحتوى العام المنشور.
- `/content/:slug` صفحة خادمية لكل مادة منشورة، فيها metadata أولية وcanonical و404 فعلي للمادة غير المنشورة.
- `/contact.html` نموذج التواصل.

تدعم إدارة المحتوى العربي والإنجليزي، المسودات والنشر المؤجل، المعاينة، سجل الإصدارات والاستعادة، سلة المحذوفات، الإجراءات الجماعية، CSV، والطباعة إلى PDF عبر مربع حوار الطباعة في المتصفح. قالب CSV يُنزّل من زر التصدير ويصلح للاستيراد؛ الحد الحالي 100 سجل لكل ملف و1 MiB. تشمل النسخة الاحتياطية الأعضاء والرتب والمحتوى وإصداراته والرسائل والوسائط والإعدادات والقوائم وسجل النشاط والزيارات، وتستثني hash كلمات المرور والجلسات.

## حدود التكامل والحماية

- البريد وWhatsApp وSMS ليست قنوات إرسال مفعلة افتراضيًا؛ الردود تُحفظ داخل قادر، وقوالب الإشعار إعدادات فقط إلى أن يجهّز المالك مزودًا واعتمادًا موثوقًا.
- المصادقة الثنائية واستعادة كلمة المرور عبر البريد، وواجهات Webhooks العامة، ومهام دورية منفصلة مثل التقارير لم تُفعّل في هذه النسخة؛ لا تُعرض على أنها جاهزة. النشر المؤجل للمحتوى يعتمد حقل موعد النشر وفحص المحتوى عند عرضه.
- لا يُفعّل تقييد IP لأن عنوان العميل خلف الوكيل غير موثق. لا تحتوي هذه الحزمة على `.git` أو `node_modules` أو أسرار بيئة؛ ثبّت الاعتماديات من ملف القفل، ووفّر إعداداتك محليًا بطريقة آمنة.

## بنية المصدر

- `server.js`, `db.js`, `llm.js`: HTTP API، الحسابات والجلسات، وخدمة المساعد.
- `admin-api.js`, `admin-db.js`: API واستعلامات لوحة الإدارة.
- `migrations/`: تغييرات قاعدة البيانات التزايدية.
- `site/`: الواجهة التعليمية وصفحات الإدارة والمكتبة والتواصل وملفات CSS/JS.
- `tests/`: اختبارات API، الصلاحيات، الحاوية، إرفاق الصور، واستيراد البيانات.
